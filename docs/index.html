Voice commands for a Raspberry Pi, in any language

Record a command 1 to 3 times, and the Pi listens for it from then on. No training, no internet, no speech-to-text.

terminal 
python3 enroll.py add "lamp on" --mic
python3 listen.py --run "./lamp.sh {command}"

How it works

A small model turns a bit of speech into 128 numbers, a voice print. The same phrase gets a similar voice print no matter who says it or in what language. The Pi keeps the voice prints of your recordings and compares everything it hears against them.

Any languageIt compares sounds, not words. Khmer, English, anything.
Your own commandsEvery home records its own. No retraining, ever.
OfflineEverything runs on the Pi. Nothing is sent anywhere.
TinyA 100 KB model. Only NumPy and a microphone needed.

Setup

A Raspberry Pi 4 or 5 with a USB microphone.

terminal 
sudo apt install python3-numpy alsa-utils
git clone https://github.com/seanghay/voice-rectifier.git
cd voice-rectifier
arecord -l   # find your microphone, e.g. card 1 → plughw:1,0

Add commands

Stay quiet for a second while it measures the room, then say the command each time you are asked.

terminal 
python3 enroll.py add "lamp on"  --mic --count 3 --device plughw:1,0
python3 enroll.py add "lamp off" --mic --count 3 --device plughw:1,0
python3 enroll.py list

Recordings work too: enroll.py add "lamp on" a.wav b.wav. Run add again to give a command more recordings, or remove to delete it.

Listen

It listens until you stop it. With --run, a program starts each time a command is heard.

terminal 
python3 listen.py --device plughw:1,0 --run "./home.sh {command}"
example output
Listening for: lamp off, lamp on  (Ctrl+C to stop)
[19:42:07] lamp on   (score 0.81)
[19:44:31] lamp off  (score 0.77)

Tips

Use two or more words"lamp on" works far better than "on".
Record 3 timesIn the room and at the distance you will really use.
Make them sound differentenroll.py warns when two commands sound alike.
Pause around itSay the command on its own, like talking to a smart speaker.
Tune itMissed commands: --threshold 0.45. Too eager: raise it. -v shows why.

Train a model

Only needed to improve the model. Training data is folders of recordings: one folder per phrase, each phrase said by several people. Every recording is randomly changed to sound like other microphones, rooms, noise and volumes.

terminal, on a computer with a GPU 
pip install -r requirements-train.txt
python prepare.py speech-commands --out data/sc
python train.py --train data/sc/train --val data/sc/val \
                --noise data/sc/noise --out runs/new --audiomentations
python calibrate.py --model runs/new --phrases data/sc/val --background talk/ --write
