      How it works

      The model was trained once to give recordings of the same phrase similar embeddings, whoever speaks. Your commands are only stored, never trained on.

      01

      Hear an utterance

      A voice detector follows the room's noise level and cuts out speech between pauses. Clicks, hiss and long talk are dropped.

      20 ms frames · ends after 500 ms of silence · max 4 s
      02

      Turn it into numbers

      A 2.5 s window around the speech becomes a log-mel spectrogram, and a small CNN maps it to 128 numbers.

      40 mels × 248 frames · 78k params · int8 · NumPy
      03

      Match

      Each command is the average of its recordings. The closest one fires if it is similar enough and about the same length.

      cosine ≥ threshold · margin 0.03 · length ±60%

      Similarity between nine recordings: three phrases, each said by three people the model never heard during training. Computed in your browser just now.

      Accuracy

      Five enrolled commands, phrases not seen in training, and an hour of non-stop background talk. Thresholds are set so at most one thing per hour is mistaken for a command.

      On a Raspberry Pi

      Pi 4 or 5 with a USB microphone. NumPy is the only dependency.

      install
      sudo apt install python3-numpy alsa-utils
git clone https://github.com/seanghay/voice-rectifier.git
cd voice-rectifier
arecord -l   # find the mic, e.g. plughw:1,0
      use
      python3 enroll.py add "lamp on"  --mic --count 3
python3 enroll.py add "lamp off" --mic --count 3
python3 listen.py --run "./home.sh {command}"

      Train your own

      Datasets are folders of <phrase>/*.wav, each phrase spoken by several people. Recordings are randomly altered to sound like other microphones, rooms and noise.

      on a machine with a GPU
      pip install -r requirements-train.txt
python prepare.py speech-commands --out data/sc
python train.py --train data/sc/train --val data/sc/val --noise data/sc/noise --out runs/new
python calibrate.py --model runs/new --phrases data/sc/val --background talk/ --write
